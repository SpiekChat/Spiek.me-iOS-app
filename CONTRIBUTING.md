# Contributing

Spiek's source is published for transparency, security review and audit
under a source-available license (see [LICENSE](LICENSE)). Because of that,
**pull requests with code are not accepted** — we cannot take code
contributions without a separate written agreement.

What is very welcome:

- **Security reports** — see [SECURITY.md](SECURITY.md) (private advisory,
  not a public issue).
- **Bug reports** — open an issue with platform, version and steps.
- **Questions and suggestions** — open an issue or email hello@spiek.me.
